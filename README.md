# БАШГРУПП × ARC AI — интерактивная карта внедрения

Открыть визуализацию: **https://akaemov.github.io/bashgroup-ai-office/**

Клиентский интерактивный документ по технической карте версии 1.1 от 16.10.2026. Это план внедрения, а не работающая система коммерческой разведки. Все карточки объектов в интерфейсе — явно обозначенные учебные примеры.

## Разделы

- Офис пяти агентов: задачи, входы, результаты, ограничения и связи.
- Этапы 0–5: работы ARC AI, участие БАШГРУПП, результаты и условия перехода.
- Путь данных: от документа до менеджера и обратной связи.
- Результаты для четырёх групп получателей.
- Чек-лист подготовки с локальными отметками в браузере.
- Архитектура, интеграции, модель данных, экономика, приёмка, хранение и вопросы для согласования.

Кнопка «Печать / PDF» раскрывает все разделы, этапы и агентов. Полная исходная карта доступна как [source.md](source.md).

## Запуск

Статические HTML/CSS/JS без зависимостей. Открыть `index.html` или разместить файлы на статическом сервере. GitHub Pages: ветка `main`, корень `/`.

Визуальный подход вдохновлён пространственной организацией [Agents Office](https://github.com/ajsahni/agents-office). Код, изображения и бренд этого проекта не используются; SVG-иллюстрация создана для данной карты.

Сайт не обращается к API и не содержит ключей, аналитики или форм передачи данных. Чек-лист хранится только в localStorage браузера. Публикация документа не является размещением будущей рабочей системы с данными клиента: её российский закрытый контур описан отдельно в карте.
